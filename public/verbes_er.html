Conjugaison des verbes en -ER

PARLER
  • jeparle
  • tuparles
  • il / elle / onparle
  • nousparlons
  • vousparlez
  • ils / ellesparlent

La grande majorité des verbes en -ER suivent ce modèle. Il suffit d'enlever -er de l'infinitif pour obtenir le radical, puis d'ajouter les terminaisons indiquées ci-contre.

!

Les terminaisons -e, -es, -ent sont muettes. Seules -ons et -ez (nous, vous) se prononcent.

Exemple
— Est-ce que vous parlez français ? — Oui, je parle français, anglais et espagnol.

Cas particuliers

COMMENCER

  • jecommence
  • tucommences
  • il / elle / oncommence
  • nouscommençons
  • vouscommencez
  • ils / ellescommencent
!

Le groupe -ce- se prononce /s/, mais -co- se prononcerait /k/. On ajoute une cédille (ç) pour garder le son /s/ dans nous commençons.

MANGER

  • jemange
  • tumanges
  • il / elle / onmange
  • nousmangeons
  • vousmangez
  • ils / ellesmangent
!

De même, -ge- se prononce /ʒ/ (comme le j de jour), mais -go- se prononcerait /ɡ/. On ajoute un -e- après le g pour garder le son /ʒ/ dans nous mangeons.

APPELER

  • j'appelle /ɛ/ (env. le è de mère)
  • tuappelles
  • il / elle / onappelle
  • nousappelons /ə/ (env. le e de petit)
  • vousappelez
  • ils / ellesappellent
!

Double l → voyelle ouverte /ɛ/. Un seul l → voyelle neutre /ə/. (Approximations : le son exact varie selon l'accent.)

ACHETER

  • j'achète /ɛ/ (env. le è de mère)
  • tuachètes
  • il / elle / onachète
  • nousachetons /ə/ (env. le e de petit)
  • vousachetez
  • ils / ellesachètent
!

Terminaison muette → la voyelle du radical devient /ɛ/ (accent grave : è). Terminaison prononcée (nous, vous) → la voyelle reste /ə/ (sans accent). (Approximations : le son exact varie selon l'accent.)
